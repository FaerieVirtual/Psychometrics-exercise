# Úvod
Mini program na trénink odhadování T skórů z percentilu a vice versa. 
Program vždy vygeneruje T skór i percentil a pak se vás zeptá na jedno z toho a porovná to s tou druhou hodnotou.
T skóry i percentily zadávejte jako celá čísla. T skóry budou vždy celá čísla a percentily mají toleranci +- 0,5.

# Instalace
1. rozklikněte https://github.com/FaerieVirtual/Psychometrics-exercise/releases/latest
2. stáhněte Source code.zip
3. extrahujte
4. vlezte do složky win-x64
5. spusťte Psychometrics Exercise, která má vpravo označení Application

**Program běží jen na windows**
